# 平台媒体接入

本 fork 在 monkeys 使用托管媒体工具.  平台管理供应商凭据, 模型, 计费和生成状态.  不要求用户配置 MiniMax key, 不把工具当 shell 命令, 不猜测 HTTP 接口或 callback token.

| 需求 | 工具 | 最小输入 |
| --- | --- | --- |
| 网页图片, 背景, 插画 | `image_generate` | `prompt` |
| 网页短视频 | `video_generate` | `prompt` |
| 旁白和朗读 | `text_to_speech` | `text` |
| 背景音乐 | `music_generate` | `prompt` |
| 其他音频素材 | `audio_generate` | `prompt` |

先检查当轮工具定义.  上表不是完整或永久 schema, 可选参数只使用实际暴露的字段和值.  不把供应商模型名, voice ID, instrumental, lyrics, camera tags 或固定时长当作通用参数.  音效等要求只有在当前音频模型明确支持时才承诺, 不把生成音频等同特定音效能力.

先确认素材的用途, 提示词, 数量和目标规格, 仅调用用户确认的项目所需工具.  已确认的同一计划不重复确认.  不因为有五种工具就全部调用, 不追加付费能力探测或循环生成来掩盖参数/文件错误.  用户修改计划后再按新范围生成.

模型支持的尺寸, 时长, 音色和格式以实际 schema 为准.  只有文本输入时, 可将视觉目标和音乐风格写进 prompt, 但不能保证精确像素或时长.  不支持的硬性要求应先说明, 不自行承诺或改用供应商直连.

音乐用 prompt 描述风格, 节奏, 乐器, 情绪和有无演唱.  若当前 schema 不支持歌词字段, 不承诺精确演唱指定歌词.  配音使用用户确认的原文; 不伪造字级时间戳, 克隆音色或未提供的音色目录.  需要字幕对齐时, 按已生成音频实测时长, 明确区分分段估计与词级时间戳.

生成完成后逐项接入:

1. 先检查结果状态.  含 error/detail 的结果记录具体原因, 不记录凭据或带授权参数的 URL.  pending/taskId 不是完成, 按当轮工具提供的状态机制等待, 不编造轮询 API, 不因等待而重复生成.
2. 终态成功后读取结果 files 中每个文件的实际 localPath, filename, mime 和 sizeBytes.  不从 URL, basename 或任务 ID 拼本地路径.  文件没有 localPath 或本地不可读时报告具体接入错误, 不用远端 URL 冒充已下载素材.
3. 在当前工作区核验文件存在, 非空且可按实际类型读取.  用 shell/文件工具复制到框架素材目录, 保持类型和扩展名一致.  Pure HTML 用 assets/, React/Next.js 用 public/assets/, SvelteKit 用 static/assets/; HTML 使用相应浏览器路径.  例如 public/assets/images/hero.png 对应 /assets/images/hero.png.
4. 按实际需要和可用工具处理素材.  图片检查尺寸, 视频和音频可用 ffprobe 时分别检查流类型和时长.  不以文件名或模型自述代替检查, 不声称未安装的依赖可用.  需要转换时真实转码后再引用, 不只更名.
5. 将素材引用写入页面, 预览后检查浏览器实际请求和媒体加载结果.  将页面, 源码和素材一起放入最终项目包, 不生成依赖沙箱绝对路径的页面.  浏览器自动播放受限时提供静音或播放按钮.

生成工具与最终交付是两个步骤.  遵守当轮工具结果的交付提示: 如果素材已自动交付, 不单独重复发送; 如果需要主动交付, 仅对最终成品使用平台提供的交付工具.  网页合成素材保留为中间文件, 完成网页或项目包再交付.  使用结果明确给出的工作区相对 deliveryPath, 不把绝对 localPath 或猜测的 basename 当作交付路径.  新生成的项目包先检查真实相对路径, 再按交付工具 schema 提交.

失败时说明工具名, 阶段, 可用的 error/detail 和已完成的文件, 保留诊断材料.  未获用户新要求不重试付费生成, 不请求供应商 key 兜底.  可用用户素材替代时先征求用户选择, 不静默换占位图或无关外链.
